# Pro Cloud Service for VCF Integrate Security, Compliance, and Resilience

## Description

This folder serves as the repository for the delivery kit and automation content for security engagements for VMware Cloud Foundation. All the files here are populated into a folder for professional services projects to perform security design, assessment, and hardening of the VCF platform.

This repository is designed to be used in combination with the [VCF Security and Compliance Guidelines](https://github.com/vmware/vcf-security-and-compliance-guidelines) and [STIG Guidance](https://github.com/vmware/dod-compliance-and-automation).

## VCF Security Controls Database
VCF 9.x security controls can also be found in the VCF Security Controls Database (SCD). This tool serves as a database for security control information including mappings to compliance and regulatory frameworks while also allowing you to generate control reports in both Excel and PDF formats to share controls with customers.
* [VCF SCD](https://brcm.tech/vcf-scd)
 
## Requirements

VMware Cloud Foundation 9.x environment deployed.

Documentation in this repo is current up to the following product versions:
* VCF 9.0

## Service Delivery Resources and Flow

### VCF Security Assessments

##### Flow

**1. Due Diligence:** 
 * Sign-off on deliverables
 * Identify key standards
 * Identify SPOC(s)
 * Create draft project schedule
 * Schedule kickoff meeting
 * Identify interviewees 

**2. Start up and Planning:**
 * Hold a kick-off meeting
 * Finalize the project schedule and interviews
 * Establish requirements for document handling
 * Request documentation
 * Finalize requirements and scope
 * Send OVA to security team (if needed)

**3. Workshop and Review:**
 * Run automated scans
 * Conduct technical workshops to review manual controls
 * Troubleshoot and remediate technical issues
 * Review and analyze documentation 

**4. Document Findings and Review:**
 * Document findings and recommendations
 * Prepare draft assessment report
 * Review draft report with key stakeholders
 * Finalize assessment report 

**4. Deliver Results:**
 * Conduct findings presentation

### VCF Security Hardening

##### Flow

**1. Due Diligence:** 
 * Sign-off on deliverables
 * Identify key standards
 * Identify SPOC(s)
 * Create draft project schedule
 * Schedule kickoff meeting

**2. Start up and Planning:**
 * Hold a kick-off meeting
 * Finalize the project schedule
 * Establish requirements for document handling
 * Finalize requirements and scope
 * Send OVA to security team (if needed)

**3. Design Workshop:**
 * Conduct Design Workshop to plan implementation
 * Review controls in Configuration Workbook
 * Determine Action Needed and Suggested Value for controls
 * Determine implementation plan

**4. Implementation and Verification:**
 * Implement controls
 * Perform post implementation verification
 * Update Verification Workbook

**4. Knowledge Transfer Workshop:**
 * Conduct Knowledge Transfer Workshop

## Usage

This is used as part of a VMware Cloud Foundation security engagement where the environment needs to be assessed or hardened. The standard bill of materials includes the following:

* **VCF Security Configuration Workbook** - Detailed workbook containing security controls for all VCF base components as well as manual assessment/remediation and automation instructions.<br>
* **VCF Security Verification Workbook** - A list of verification steps for security controls and documenting security control configurations.<br>
* **VCF Security Engagement WBS** - This is a work breakdown structure for the engagement, which lists detailed tasks which were used to develop the Level of Effort.<br>
* **VCF Security Design Workshop** - This is the design workshop associated with the high level design construct.<br>
