# VMware Pro Cloud Service for Private Cloud (VCF Version 9.0)

## Description

This folder serves as the repository for the delivery kit and automation content for a VMware Pro Cloud Services for Private Cloud engagement with VMware Cloud Foundation. All the files here are populated into a folder for professional services projects projects to perform a standardized VCF platform build.

## Federal/DoD/IC Environments
Design and build VCF delivery kit and automation content is the same across Private, Federal, Department of Defense (DoD), Intel Community (IC) sectors. Specific instructions for hardening Federal/DoD/IC environments can be found in the readme file of the **2. VCF NIST Hardening** directory.

## Installation

Installation is performed in one of three ways for a VMware Pro Cloud Service for Private Cloud:
* **Manual Installation** - This requires manual installation and configuration of all pieces of the infrastructure.
* **PowerShell** - all of the documentation lists powershell commands which can be run to automate configurations. Note that for VMware Validated Solutions One-Click installations can be performed automating much of the step by step powershell configurations.
* **Terraform** - Is available for many of the components which further automates the installation where Terraform modules are available.

## Requirements

The main requirement for configuring the VMware Pro Cloud Service for Private Cloud is that appropriate hardware be available to configure the components. This will be discussed in more depth during the project's design phase. Once the hardware is available, racked, and stacked, and the network configuration set is deployed, swiftly proceed.

## Usage

This is used as a part of a VMware Pro Cloud Services engagement where VMware Cloud Foundation is being deployed, along with respective Management components, to build a standardized foundation for a deployment.  This standardized high-level design is created in the root of this directory, which includes the following:

* **VMware Pro Cloud Services for Private Cloud** - High Level Design Word document- This is the high level design document used to document the customer specific requirements, the conceptual design, and the logical design.
* **VMware Pro Cloud Services for Private Cloud** - Design Workshop Powerpoint presentation - this is the design workshop associated with the high-level design construct.
* **VMware Pro Cloud Services for Private Cloud** - Design Diagrams Visio/Powerpoint - these files contain the design diagrams associated with the high level design. There are two files, since the VCF Division is providing in powerpoint for this release, however certain elements are only available in Visio.
* **VMware Pro Cloud Services for Private Cloud** - Design Library - This is the Design Library of additional design decisions which are available for VCF 9.0.
* **VMware Pro Cloud Services for Private Cloud** - Requirements Traceability Matrix v1.0 workbook - This is the standard RTM document, which is a part of the standard architecture delivery kit.
* **VCF Planning and Preparation Workbook** - a copy of the current planning and preparation workbook as downloaded from the documentation.


Each of the folders here in this repository have a standard bill of materials which includes the following documents:


* **Prerequisite Checklist** - A listing of different prerequisites which are applicable to the part of the engagement being performed.
* **Low-Level Design Document** - A detailed design doc, which normally is used as a deliverable for customer engagement.
* **Low-Level Design Diagrams** - Visio/Powerpoint containing the different design decisions used for the engagement.
* **Design Decisions Workbook** - An Excel document that lists all of the design decisions used in this phase of the design.
* **Engagement WBS** - This is a work breakdown structure for the engagement, which lists detailed tasks which were used to develop the Level of Effort. 
* **KTWorkshop** - This are the latest powerpoint decks for whats new and technical enablement of the product.
* **Installation and Configuration Procedures document** - This lists the detailed steps to perform the installation and configuration of the component.  Note that if automation is used, this document will only be used for reference. 
* **Processional Services Runbook** - This document lists the different post-installation tasks that are required to standardize Pro Cloud Services Engagements.
* **Standard Operating Procedures Document** - Lists day two tasks which may be useful post deployment of the solution.
* **Verification Workbook** - a list of verification checks to validate the functionality of the environment post-deployment
